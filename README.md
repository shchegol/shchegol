### Hi 👋

I'm a solo developer based in Spain, building small practical tools — mostly things I needed myself and couldn't find anywhere else.

**Currently building:** [Rowing Bridge](https://github.com/shchegol/rowing-bridge) — an Android app that connects to a Bluetooth rowing machine and a Garmin watch, records your workout, and writes a real `.FIT` file for Garmin Connect / Strava. Built after discovering that Garmin Connect IQ apps silently drop the metrics they're supposed to save.
